## Projetos em destaque

### [MONITOR-RPA](https://github.com/GRUPO14D/MONITOR-RPA)

Dashboard full-stack para monitoramento em tempo real de 15 RPAs em produção.

- Autenticação via token nas rotas POST/GET
- Deploy contínuo via Vercel + pm2 no servidor
- Backend Node.js/Fastify + Frontend React/Vite + PostgreSQL (Neon)

**Stack:** TypeScript · React · Vite · Fastify · PostgreSQL

---

### grupo14d-toolkit

Espinha dorsal técnica do ecossistema de RPAs do Grupo 14D. Centraliza a infraestrutura de telemetria, monitoramento e auditoria de todos os robôs.

- Pacote `grupo14d-telemetry`: reporte de eventos e heartbeats via thread daemon, distribuído via PAT no `requirements.txt`
- Audit Engine: auditoria estática dos 15 RPAs (~47k LOC), roadmap de saneamento e matriz de riscos
- 77 testes unitários · 100% verdes · Docs API (FastAPI)

**Stack:** Python · FastAPI · Pytest · PyInstaller

---

### RPA-IRPF

Ecossistema de automação para processamento de declarações de IRPF em ambiente contábil.

- RPA-016 (watcher): polling via SMB com watchdog, detecção automática de novos arquivos
- RPA-017 (sync): sincronização de dados com Google Sheets
- Módulo de fluxo de caixa integrado — todos em produção sob pm2

**Stack:** Python · Google Sheets API · pm2 · Watchdog

---

### [MyBuddy](https://github.com/EderHenriq/MyBuddy)

Plataforma que centraliza adoção, serviços, eventos e marketplace pet — conectando adotantes, ONGs, pet shops e clínicas veterinárias.

- Autenticação federada com **Keycloak 26**
- Pagamento integrado via **Mercado Pago**
- App mobile em **Flutter** + Web em **Angular**

**Stack:** Java 21 · Spring Boot 3 · Angular · Flutter · Keycloak · Docker · MongoDB · PostgreSQL

> Projeto acadêmico (TCC) · Time de 4 devs
